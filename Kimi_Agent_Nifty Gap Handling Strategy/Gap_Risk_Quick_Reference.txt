IF Strike becomes ITM or ATM after gap:
  → EXIT IMMEDIATELY (market order if needed)
  → Do not hope for recovery
  → Accept the loss

IF Strike still OTM but within 0.5%:
  → Monitor for 15-30 minutes
  → If continues against you → EXIT
  → If stabilizes → Tighten stop to 1%

IF Strike still OTM (>1% away):
  → Hold but monitor closely
  → Set alert at 0.5% from strike
  → Be ready to exit

📈 GAP-RISK POSITION SIZING FORMULA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Standard:     Lots = (Capital × Risk%) / (Stop × Lot Size)

Gap-Adjusted: Adjusted Risk% = Standard Risk% / Gap-Risk Factor
              Gap-Risk Factor = 1 + (Expected Gap% × 2)

Example (Monday):
Capital = Rs.500,000 | Standard Risk = 2% | Expected Gap = 1%
Gap-Risk Factor = 1 + (0.01 × 2) = 1.2
Adjusted Risk% = 2% / 1.2 = 1.67%
Adjusted Lots = (500,000 × 1.67%) / (100 × 25) = 3.3 → 3 lots

Result: 25% reduction in position size

💡 ALTERNATIVES TO AVOID GAP RISK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INTRADAY-ONLY:
   - Enter 10:00 AM - 11:00 AM
   - Exit 2:30 PM - 3:00 PM
   - No overnight risk
   - Sleep peacefully on weekends

2. IRON CONDOR (Hedged):
   - Max loss DEFINED
   - Gap of 2% = loss of Rs.100 (not Rs.500+)
   - Lower margin requirement

3. SKIP MONDAYS:
   - Close Friday 3:15 PM
   - No new positions until Tuesday 10:00 AM
   - Eliminates 80% of gap risk
