📊 VOLUME PROFILE COMPONENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POC  → Point of Control (Highest Volume) → FAIR VALUE → Price Magnet
VAH  → Value Area High (70% upper bound) → RESISTANCE → Sell Calls Above
VAL  → Value Area Low (70% lower bound) → SUPPORT → Sell Puts Below
HVN  → High Volume Node → Strong S/R → Confluence Trading
LVN  → Low Volume Node → Breakout Zone → Avoid Selling Here

🎯 5 STRIKE SELECTION APPROACHES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─────────────────────────────────────────────────────────────────────────────┐
│ APPROACH 1: POC-Based (Mean Reversion)                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ • Call Strike = POC + (1.5% to 2.5% buffer)                                │
│ • Put Strike  = POC - (1.5% to 2.5% buffer)                                │
│ • Buffer: 0-2 DTE = 1.5% | 3-7 DTE = 2.0% | 7+ DTE = 2.5%                  │
│ • Best For: Range-bound markets                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ APPROACH 2: VAH/VAL-Based (Range Trading)                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ • Call Strike = VAH + (0.5% to 1.0% buffer)                                │
│ • Put Strike  = VAL - (0.5% to 1.0% buffer)                                │
│ • Confirm with price rejection at levels                                    │
│ • Best For: Established ranges                                              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ APPROACH 3: HVN Confluence (High Probability)                               │
├─────────────────────────────────────────────────────────────────────────────┤
│ • Find HVN cluster + Fibonacci level (50%, 61.8%, 78.6%)                   │
│ • Sell strike beyond confluence zone + 1% buffer                           │
│ • Requires 2+ confluence factors                                            │
│ • Best For: Swing trading (5-10 DTE)                                        │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ APPROACH 4: VWAP + Volume Profile Hybrid                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ • VWAP > POC → Bullish → Sell Puts                                          │
│ • VWAP < POC → Bearish → Sell Calls                                         │
│ • Strike distance: 0-1 DTE = 1% | 2-3 DTE = 1.5% | 4+ DTE = 2%             │
│ • Best For: Intraday selling                                                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ APPROACH 5: Delta-Adjusted Volume Profile                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ • Target delta based on DTE:                                               │
│   - 0-1 DTE: 5-10 delta | 2-3 DTE: 10-15 delta                             │
│   - 4-7 DTE: 15-20 delta | 7+ DTE: 20-25 delta                             │
│ • Align delta target with volume-based level                                │
│ • Best For: Risk-defined selling                                            │
└─────────────────────────────────────────────────────────────────────────────┘

⏰ ENTRY/EXIT RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ENTRY WINDOW:     10:00 AM - 2:30 PM IST (Avoid 9:15-9:35 AM, 3:00-3:30 PM)

ENTRY CONDITIONS:
  ✓ Volume Profile levels calculated (POC/VAH/VAL)
  ✓ Strike selection criteria met
  ✓ Minimum 1% OTM buffer
  ✓ No major news events
  ✓ Risk per trade ≤ 2% of capital

EXIT RULES:
  ✓ 50% Profit Target → Close 50% position
  ✓ Trail remaining with 20% trailing stop
  ✓ Hard Stop: 200% of premium received
  ✓ Time Stop: Exit if holding > 5 days
  ✓ Expiry Exit: Close by 3:15 PM on expiry day

🛡️ RISK MANAGEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POSITION SIZING:
  Position Size = (Capital × 2%) / (Stop Loss Points × Lot Size)

DAILY LIMITS:
  • Daily Loss Limit:     4% of capital → STOP TRADING
  • Weekly Loss Limit:    8% of capital → REDUCE SIZE 50%
  • Monthly Loss Limit:   12% of capital → PAUSE & REVIEW
  • Max Concurrent:       5 positions

ADJUSTMENT RULES:
  • 25% Loss → Monitor closely
  • 50% Loss → Roll strike or convert to spread
  • 100% Loss → EXIT (hard stop)

💡 PRO TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. POC is your PRIMARY reference - always know where it is
2. Use PREVIOUS DAY's completed profile for reliability
3. Check bid-ask spread before entry (< 10% of premium)
4. Avoid selling before major events (RBI, Budget, Results)
5. When in doubt, use wider strikes (higher buffer)
6. Always have a stop-loss defined BEFORE entry
7. Don't average losers - exit and reassess
8. Keep a trading journal - review weekly

📞 KEY FORMULAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Strike Selection (POC-Based):
  Call = POC + (Spot × Buffer%)
  Put  = POC - (Spot × Buffer%)

Position Size:
  Lots = (Capital × Risk%) / (Stop Points × 25)

Expectancy:
  E = (Win% × Avg Win) - (Loss% × Avg Loss)

Profit Factor:
  PF = Gross Profit / |Gross Loss|
